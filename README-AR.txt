CLAIMAXIS — النسخة الكاملة ذات المجلد الواحد
============================================

هذه النسخة لا تحتوي على مجلد functions.
كل ملفات الموقع وملف التشغيل الخلفي موجودة في نفس المجلد.

المهم:
- _worker.js يشغل كل روابط API.
- D1 Binding يجب أن يبقى اسمه DB.
- Secret يجب أن يبقى اسمه ADMIN_TOKEN.

طريقة الرفع من الآيفون:
1) فك ضغط الملف.
2) افتح مستودع GitHub.
3) احذف ملفات ومجلد functions القديمة من المستودع، خصوصًا أي ملفات API قديمة.
4) ارفع كل الملفات الموجودة داخل هذا المجلد إلى الصفحة الرئيسية للمستودع.
5) تأكد أن _worker.js ظاهر بجانب index.html في الصفحة الرئيسية.
6) انتظر نشر Cloudflare الجديد.
7) افتح https://claimaxis.com/api/health

النتيجة الصحيحة يجب أن تحتوي:
"ok": true
"database": true
"schema_ready": true

بعدها جرّب الاستبيان ثم افتح:
https://claimaxis.com/dashboard.html
